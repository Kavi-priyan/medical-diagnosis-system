## Medical Diagnosis System Using Streamlit

An intelligent, interactive, and user-friendly web application for early detection of multiple diseases using machine learning and Streamlit.

## 🚀 Overview
The Medical Diagnosis System empowers users to assess their health by predicting the likelihood of:

Diabetes:
-  Diabetes
-  Heart Disease
-  Parkinson’s Disease


Built with Python and Streamlit, this application leverages pre-trained machine learning models to deliver real-time, accurate predictions through a clean and responsive interface.

______________________________________



## 🧠 Features
- Multi-Disease Prediction: Utilizes dedicated models for each condition.

- Streamlit Web Interface: Offers a fast, interactive, and browser-based UI.

- Pre-trained Models: Includes .sav files for diabetes, heart disease, and Parkinson’s.

- Modular Codebase: Structured for easy extension and maintenance.

- Lightweight Deployment: Runs locally without the need for cloud services.

## ⚙️ Technologies Used
- Python 3.x

- Streamlit

- scikit-learn

- NumPy

- Pandas
